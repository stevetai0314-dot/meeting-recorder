# 外銷部會議錄音工具

錄音頁面網址（直接點開用）：

**https://stevetai0314-dot.github.io/meeting-recorder/recorder.html**

用法：開始錄音 → 選整個螢幕並勾「分享系統音訊」→ 瀏覽器接著會跳出麥克風權限請求，按「允許」才能同時錄到自己講話的聲音（不允許也可以，會自動改成只錄系統音訊）→ 會議結束按停止錄音 → 填備註（選填）→ 附討論文件 PDF（選填，可多選，合計 15MB 內）→ 按「☁ 上傳分析」。

- 逐字稿與摘要記錄在 Google Sheet「外銷部會議記錄」
- 會議 MD 筆記存在 Google Drive「會議紀錄」資料夾
- 附的 PDF 存在錄音同一個資料夾，Sheet 第 8 欄「文件連結」

部署設定步驟見 [SETUP.md](SETUP.md)。
